# 青岚 · 古风蓝青色静态网站

一个多文件、纯静态的古风个人展示站，以蓝青色为主调，水墨山水为视觉意象。采用原生 HTML + CSS + JavaScript，无构建、无第三方依赖，用浏览器直接打开即可运行。

---

## 目录结构

```
源码/
├── index.html       首页：导航、Hero、简介、统计、四时雅趣、佳作预览、赞赏区、页脚
├── about.html       关于：青岚小传、岁月之痕时间轴、立身之旨、引文
├── works.html       作品：尺素六帧画廊、题画语
├── contact.html     联系我们：驿传信息、留言表单、赞赏区
├── assets/
│   ├── css/style.css    共享样式（主题变量、全部动效、响应式、reduced-motion）
│   ├── js/main.js       共享脚本（导航、滚动揭示、视差、赞赏切换、回顶、表单）
│   └── img/
│       ├── wechat-qr.jpg   微信收款二维码
│       └── alipay-qr.jpg   支付宝收款二维码
└── README.md
```

---

## 如何运行

- **直接打开**：双击 `index.html`，在浏览器中浏览即可。页面与 `assets/` 需保持同目录（图片、样式、脚本均为相对路径引用）。
- **本地服务器**（可选）：在项目目录下启动任意静态服务，例如 `python -m http.server 8000`，访问 `http://localhost:8000`。
- 若需把站点转给别人，请连 `assets/` 目录一起发送。

## 功能特性

- **蓝青古风视觉**：宣纸米 + 黛青 / 青碧 / 青花蓝，朱砂印章点缀；衬线字体承载古意。
- **滚动揭示动画**：元素进入视口浮现、离开视口回退，向下/向上滚动均可反复触发（IntersectionObserver 双向）。
- **山峦视差**：Hero 三层山峦随滚动错位移动。
- **跨文档过渡**：页面跳转带淡入淡出过渡（View Transitions API，需 Edge / Chrome 115+；旧浏览器自动回退普通跳转）。
- **移动端抽屉导航**：窄屏下汉堡菜单展开与收起。
- **赞赏区**：微信 / 支付宝二维码单面板互斥切换。
- **回到顶部**：滚动超一定距离后出现。
- **表单提示**：提交后显示收讫提示（纯前端演示，不实际发送）。
- **无障碍**：尊重 `prefers-reduced-motion`，关闭动效时仍可正常浏览。

## 定制指南

- **替换文案**：直接编辑各 `.html` 文件中的文字。
- **更换二维码**：将新的收款码图片命名为同名文件，覆盖 `assets/img/wechat-qr.jpg`（微信）与 `assets/img/alipay-qr.jpg`（支付宝）。
- **更新联系方式**：修改 `contact.html` 中“驿传之所”区块的邮箱 / QQ / 住址。
- **调整配色**：`assets/css/style.css` 顶部 `:root` 内的主题变量（`--cyan-500`、`--indigo` 等）。
- **统计数字**：首页 / 关于页的统计数值位于对应 HTML 的 `data-count` 属性中，可改为真实数据。

## 技术说明

- **技术栈**：原生 HTML / CSS / JavaScript，无构建工具、无框架、无包管理器。
- **字体**：思源宋体（Noto Serif SC），经自托管镜像 `https://miaoda.feishu.cn/fonts/css2` 引入，字体加载失败时回退到系统衬线字体。
- **浏览器支持**：Edge / Chrome 115+ 可体验完整动效；较旧浏览器降级为无过渡、可正常浏览。
